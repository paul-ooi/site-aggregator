DubBot has two new updates designed to make life easier for our account administrators. Whether you're managing user accounts or configuring authenticated website crawls, these updates help reduce administrative effort and simplify those workflows.

## Build Multi-Step Logins Directly in DubBot

Many websites require more than just a simple username and password combination to authenticate. Previously, configuring these login flows could be challenging. But with the new [Scripted Authentication Builder](https://help.dubbot.com/en/articles/15361309-scripted-authentication-builder "This link leaves the DubBlog website."), administrators can now create multi-step login sequences directly within the DubBot interface.

The builder supports common authentication actions, including Click, Fill field, Go to URL, Type, Wait for milliseconds, Wait for selector, and Wait for URL.

This makes it easy to configure authentication for sites that require multiple login screens, redirects, or timed interactions before a crawl can begin.

### Benefits for administrators

-   Configure complex login workflows without leaving the application.
-   Improve crawl reliability for authenticated websites.
-   Reduce setup time when onboarding protected sites.
-   Adapt to a wider variety of authentication processes.

## Simplify User Access Requests

Managing user permissions is now more streamlined than ever with the new [Account Contact Email](https://help.dubbot.com/en/articles/15554653-account-contact-email-added "This link leaves the DubBlog website.") feature.

Administrators can specify a single email address to appear in each user’s Account Access panel. When a user selects **Need to make changes to your account access?**, DubBot opens a pre-populated email with the user’s name and a request template, making it easier to submit complete and accurate access requests.

Administrators can specify a single email address for all account users to request changes to their DubBot account access. When a user selects Need to make changes to your account access? in the Account Access Panel, DubBot opens a pre-populated email with the user’s name and a request template, making it easier to submit complete and accurate access requests.

For organizations where multiple people manage accounts, a shared group email address can be used so requests are automatically routed to the appropriate team.

### Benefits for administrators

-   Establish a consistent process for requesting account changes.
-   Reduce back-and-forth communications by automatically including user details.
-   Route requests directly to the correct team.
-   Simplify user administration across your organization.

These updates demonstrate DubBot's continued focus on reducing administrative overhead while making it easier to manage both authenticated scanning and user access.

If you'd like to set up the **Account Contact Email** feature or have questions, contact the DubBot team through the in-app chat or by emailing us at [help@dubbot.com](mailto:help@dubbot.com "This link leaves the DubBlog website.").
